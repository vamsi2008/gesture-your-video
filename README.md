# Gesture Video public website v2.1.1

Upload ALL contents of this folder to the GitHub repository root, keeping assets/ and vendor/ intact. Enable Settings → Pages → Deploy from a branch → main → /(root). After deployment, hard-refresh the page.

Select a video, then enable the camera. One finger pauses; two fingers play; thumb right plays at 2×; thumb left rewinds in small jumps. Camera stops at the end or when leaving the page.

This public build supports same-device playback only. Phone/laptop pairing requires the separate local app. Videos and camera frames stay on the device.
